# Dhanraj Gaikwad — Personal Portfolio

A responsive portfolio for a QA engineer specializing in Guidewire ClaimCenter, Selenium, Java, and test automation.

## Features

- Professional portrait and animated CSS 3D graphics
- Selected work, experience, technical skills, and certifications
- Downloadable résumé and direct LinkedIn, email, and phone links
- Accessible project dialogs and reduced-motion support
- Contact form with required-field and email validation

The contact form opens a prefilled email in the visitor's email application. It does not send or store messages on a server.

## Run locally

No build tools or dependencies are required. Serve this directory with any static web server, for example:

```sh
python -m http.server 4174
```

Open `http://localhost:4174`.

## GitHub Pages

In repository Settings → Pages, select **Deploy from a branch**, branch **main**, and folder **/(root)**.

## Edit

- `index.html`: page content and links
- `styles.css`: responsive design and animations
- `app.js`: contact form, project dialogs, and motion controls
